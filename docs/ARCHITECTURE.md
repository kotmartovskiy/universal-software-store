# Architecture

Layers:
1. Identity — software, developer, product family.
2. Release — version and release date.
3. Package — APK, EXE, SIS, JAR, DEB, disk image, ROM image, etc.
4. Platform — OS family/version, CPU architecture, ABI/runtime.
5. Device — concrete model and capabilities.
6. Compatibility — native, dependency-assisted, compatibility-layer, emulated, partial, unavailable.
7. Provenance — source, signature, hash, verification and modification state.
8. Distribution — official source, mirror, local NAS, archive reference.
9. Launch — native launcher, VM, emulator or compatibility layer.

A catalog record does not imply redistribution rights. Metadata may exist while download remains unavailable.
